# 使用指南

[English](en/PRODUCT.md) · [文档目录](INDEX.md) · [项目首页](../README.md)

本页说明日常操作和任务行为。安装步骤见[本地使用](LOCAL.md)或[生产部署](DEPLOYMENT.md)，模型接入见[供应商](PROVIDERS.md)。

## 从项目开始

登录后添加已有项目，或在允许的目录下创建项目目录。路径始终指向运行后端的机器，不能通过填写路径直接访问浏览器设备的文件。服务账户需要拥有相应目录权限。

项目可以设置附加提示词，用于说明编码规范、验证要求和项目背景。提示词最多 50000 字符；它不是操作系统权限规则。移除项目只移除工作台索引，不删除磁盘上的源码。

选择项目后新建会话，再选择模型和执行权限。使用源码管理保存基线，有助于检查模型造成的文件修改；普通目录也能运行，但没有 Git 提供的变更基线。

## 项目上下文

“添加项目”弹窗顶部的自动压缩滑条始终可用，无需先勾选 1M。可选 50%、60%、70%、80%、90% 五档，默认 90%。每轮最终回复完成后，CLI 按当前模型的可用上下文检查比例并压缩；原有压缩保护仍然生效。

勾选“启用 1M 上下文”后，额外请求 1,000,000 Token 窗口，并显示对应 Token 阈值，例如 70% 为 700,000 Token。模型与供应商须支持该容量。设置按项目持久化，应用于会话新建、恢复、分叉和排队执行，不修改全局 CLI 配置。已有项目缺省为 1M 关闭、比例 90%。CLI 兼容性与配置字段见[配置说明](CONFIGURATION.md#项目级上下文设置)。

## 跨会话记忆与协作

“设置 → 常规 → 记忆与协作”提供两个独立开关，默认均关闭。开启记忆后，侧栏出现“记忆库”；可手动新增项目记忆或跨项目记忆，也可在消息操作中点击“保存记忆”。记忆内容和使用范围可编辑，也可停用或删除；每轮最多引用 6 条完整记忆，总长度不超过 4000 字符，引用记录只包含实际发送的条目。执行新一轮消息时，后端按当前项目和消息内容选取相关记忆加入参考资料；排队消息在实际执行时选取。关闭开关后不再检索或新增记忆。已经写入原生会话历史的旧内容仍属于该会话历史。当前记忆库最多展示最近 500 条，关键词检索最多扫描适用范围内最近 200 条启用记忆；尚不支持语义检索或大规模记忆分页。

开启协作后，侧栏出现“协作”。协作组使用已有会话，可跨项目，会话选择器最多加载 10 页（通常为 600 条），允许填写共同目标、每个会话的要求、下一位会话和最多执行步数。启动时输入本次任务；每轮完成后将最终回复交给下一位，直到达到步数上限。会话菜单可从当前会话进入新协作配置。同一协作组只能有一个未结束运行；协作运行可暂停、继续或结束；关闭协作开关会暂停后续交接，正在运行的轮次仍可能完成。

协作只传递文字回复，不自动传递附件或开放其他项目文件。使用者应在交接前核对敏感内容。执行容量不足时，协作会暂停，不会加入普通消息队列；容量释放后可手动继续。服务重启、执行器断线、发送结果不明确或轮次失败时，运行暂停并等待核对，不会自动重复发送。已确认失败或中断的轮次，点击“继续”会使用原输入重新提交当前步骤；请先核对已执行的操作，避免重复操作。提交结果不明确的运行可结束自动交接，但原生任务仍需在会话历史中核对。交接优先使用最终回复，不混入中途进度消息。一个参与会话同时只接受一条协作运行；运行期间普通消息需先暂停或结束该协作。

## 组织会话与输入

会话支持分页、置顶、重命名、分叉、归档和永久删除。分叉用于从已有上下文继续另一条工作路线，不会复制或隔离项目文件。永久删除需要确认，不能当作撤销项目改动。归档会话不会被删除；在“设置 → 归档会话”中可按项目查看并恢复，恢复后重新进入对应项目的最近会话列表。归档列表按项目独立分页，点击“刷新”可重新读取当前归档状态。

打开会话后，点击工作区右上角的搜索图标可查找当前会话内容。输入关键词会显示匹配总数并定位第一处；用“上一个”“下一个”或 Enter、Shift+Enter 在匹配项之间循环。搜索时会先加载该会话尚未展示的历史分页，历史加载失败时会提示当前只能搜索已加载内容。新建会话按钮占满侧栏顶部一行。

发送前可添加附件、引用对话片段或引用项目文件。单次消息最多 10 个附件、10 个文件引用和 5 个对话引用；每个上传文件最多 20 MiB。文件引用让执行器按需读取服务器文件；上传则把本地文件保存到工作台的数据目录。

草稿保存在当前浏览器标签页的会话存储中，退出登录后清除，不跨设备同步。附件有独立的服务端状态；发送前检查所属会话，不要把草稿保留理解为已提交任务。

## 运行中的操作

| 操作           | 行为                                                |
| -------------- | --------------------------------------------------- |
| 发送           | 创建新一轮任务，使用本轮选择的模型                  |
| 加入队列       | 保存后续任务；正常完成后按调度条件继续              |
| 补充指令       | 尝试把新指令加入当前轮次，沿用当前模型              |
| 停止           | 请求中断当前轮次；已执行的文件/工具操作不会自动撤销 |
| 强制停止执行器 | 影响本实例执行器的全部任务，不能只按当前会话理解    |

同一项目和不同项目的多个会话均可并行，统一受 `MAX_CONCURRENT_TURNS` 限制（默认 3）。单个会话一次只执行一轮，后续消息按会话排队。同项目会话共享磁盘文件，不会自动隔离工作目录。失败、中断或服务重启后，相关队列暂停，需要确认后继续。关闭浏览器或断网通常不会停止后端任务。

任务可能等待命令审批、文件变更审批、权限请求、模型追问或 MCP 输入。根据实际请求作答；多个页面同时回答时，已处理的请求不会重复生效。权限和沙箱最终取决于 CLI、操作系统与选定策略，项目目录选择范围并不构成执行沙箱。

页面会显示流式回复、工具记录、计划、差异和接口提供的思考内容。等待或断线后先检查任务状态与历史，不要立即重复发送相同任务。

等待执行或已暂停的队列消息可点击旁边的铅笔按钮编辑。弹窗读取完整正文，不受队列摘要长度限制；保存后保留附件、引用、模型设置和排队位置，原本暂停的队列仍保持暂停。其他已连接页面会同步更新。如果消息已经开始提交，或其他页面先保存了修改，本次保存会被拒绝，草稿仍保留在弹窗中供复制。打开编辑窗口本身不会暂停队列；已经提交的消息不能通过队列修改。

## 查看文件与改动

文件面板支持目录浏览、文本查看、行列定位和下载。Git 差异反映当前磁盘与 Git 基线的差异，会话差异来自执行记录；两者可能不同。查看差异不会恢复文件，也不替代测试。

图片可在抽屉预览、放大、缩放并适应窗口；支持 PNG、JPEG、GIF、WebP、AVIF、BMP、ICO、SVG，预览上限 20 MiB。文本读取上限 2 MiB，目录每页最多 1000 项。超限、不支持或解码失败时按界面提示下载查看。图片文件预览与模型能接受的图片输入格式是两套能力。

原生代码审查和上下文压缩通过 CLI 执行。压缩改变模型上下文；“清理缓存”只是工作台维护操作，二者不是同一个功能。

## 设置与维护

| 设置范围   | 用途                                         |
| ---------- | -------------------------------------------- |
| 常规与界面 | 主题、个人模型筛选等偏好                     |
| 项目       | 项目提示词与目录管理                         |
| 归档会话   | 按项目查看并恢复已归档会话                   |
| 供应商     | 保存配置、获取模型、切换线路、查询支持的余额 |
| 扩展与迁移 | Skills、MCP、导出与导入迁移包                |
| 执行环境   | CLI 状态和版本更新                           |
| 数据       | 用量统计、缓存与日志维护                     |
| 账户       | 网站密码与登录管理                           |

用量中的缓存输入是输入 Token 的子集，思考 Token 属于输出部分，不应再次累加。统计不是供应商结算账单。备份范围和恢复流程见[运维](OPERATIONS.md)。

## 使用边界

工作台面向共享信任范围内的使用者：没有成员角色、多租户隔离、支付计费、GitHub OAuth、网页文件回滚或集群调度。所有用户共享操作系统服务账户及全局供应商。工具能访问的文件、网络和命令由实际执行权限决定。

## 导出当前会话

在右上角会话菜单点击 **导出当前会话**，在弹窗中选择 TXT、Markdown 或 HTML，再点击“导出文件”。导出范围是当前打开会话的完整可用历史，按时间先后排列，包含未加载的旧消息、已公开的思考内容、工具输出与文件差异，不包括其他会话或项目。运行中的回复仅包含导出时已读取到的内容。

TXT 便于直接阅读与复制；Markdown 保留消息排版源码；HTML 是独立网页，回复按 Markdown 排版，工具输出保持原文，可离线打开和打印。图片、附件保留引用信息，不嵌入原文件；HTML 不自动加载远程图片或执行消息中的代码。空会话也可导出。读取历史不会启动模型任务或查询供应商余额；分页失败时保留弹窗供重试，不下载残缺文件。

## 在线预览项目 HTML

在文件面板打开 `.html` 或 `.htm` 文件即可查看页面，用“预览 / 源码”切换显示方式；带行号的文件链接会直接打开源码视图。点击“刷新文件”重新加载预览。支持内联脚本、相对路径 CSS/图片/字体/音视频及 JavaScript 模块，也允许加载 HTTPS 托管的脚本、样式、图片和字体。

页面在隔离环境中运行，不能读取工作台 Cookie 或父页面；预览不提供项目后端、表单提交或任意 API 代理。相对资源从 HTML 所在项目目录解析，使用站点根绝对路径或依赖自身路由/后端的应用应启动项目服务后访问。隐藏文件和非静态资源不会通过预览提供。HTML 上限 2 MiB，单个资源上限 20 MiB。预览地址一小时后失效，退出对应登录会话也会失效，刷新可重新生成。
