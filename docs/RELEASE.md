# 更新记录

[English](en/RELEASE.md) · [文档目录](INDEX.md) · [项目首页](../README.md)

本页记录源码中的用户可见变化及升级注意事项，不表示某个服务器已经部署。`package.json` 当前版本为 `1.0.0`，下列维护更新按日期区分。具体测试证据应随发布记录保存，验证方法见[测试与验收](VALIDATION.md)。

## 2026-10-11：项目更名为 Codex Cloud

界面、文档、包名、新安装的服务与默认目录、导出文件名统一使用 Codex Cloud。迁移导入仍接受更名前生成的备份包。已有部署应保留实际数据目录、Codex 主目录和服务账户；若改用新的服务名或目录，先停止旧服务并按[运维指南](OPERATIONS.md)备份和迁移，避免两个实例同时使用同一数据目录。

## 2026-10-11：扩展列表精简

设置中的 Skills 和 MCP 列表项只显示名称与操作按钮，移除列表里的介绍、连接命令和状态说明。编辑表单仍可查看和修改完整配置。

## 2026-10-11：会话内搜索入口

侧栏顶部移除新建会话旁的搜索按钮，新建按钮扩展为整行宽度。会话工作区右上角新增搜索入口，输入关键词后高亮并定位匹配内容，支持计数、上一处和下一处切换；搜索会补齐当前会话的历史分页。

## 2026-10-11：归档会话管理

设置新增“归档会话”标签，按项目独立读取、分组和分页显示归档内容。会话可逐条恢复；恢复成功后立即从归档页移除，并通过实时事件同步工作台的最近会话列表。空项目不显示，加载失败的项目保留错误信息供刷新重试。

## 2026-10-11：队列编辑与项目 HTML 预览

待发送和暂停中的消息支持完整正文编辑，保留附件、引用、模型设置及队列顺序；并发修改或开始提交时会检测冲突，发送器使用最后保存的正文。项目 HTML 文件可在隔离预览与源码间切换，支持相对静态资源和 JavaScript 模块；预览授权临时有效，并绑定原登录会话。

## 2026-10-11：会话导出与终止图标

右上角会话菜单新增 TXT、Markdown、独立 HTML 三种导出格式，包含当前打开会话的完整可用历史和浏览器未加载的旧分页，保留工具输出与文件差异；失败不下载残缺文件，支持取消导出。强制终止执行器改用带叉八边形图标，与普通停止按钮区分。

## 2026-10-11：独立压缩比例与源码导出

“添加项目”提供可选 1M 上下文，以及独立可调的 50%～90%、步长 10% 自动压缩滑条，默认 90%。CLI 在每轮最终回复结束后按模型可用窗口检查比例。开启 1M 还会设置窗口及 Token 阈值，详见[配置说明](CONFIGURATION.md)。设置按项目持久化，应用于会话新建、恢复、分叉和排队执行。

新增 `python3 scripts/export-source.py`，无需安装依赖或构建即可导出干净源码。脚本只复制 `scripts/source-files.txt` 中已审阅的文件，校验复制内容，拒绝覆盖已有目录，排除真实环境、运行数据与构建文件。使用方法见[源码交付](SERVER-SOURCE.md)。

## 2026-10-11：多会话并行

同一项目和不同项目的多个会话现在都可并行执行，共享全局并发上限；单个会话保持串行，超过上限的任务排队。正在启动的任务也占用并发名额。安装器和 Linux 模板的默认并发数统一为 3。

升级已有实例时，检查实际运行目录的 `.env`：若仍为 `MAX_CONCURRENT_TURNS=1`，按所需容量改为 `3`（支持 1～16），部署新版本并重启后生效。程序升级不会自动覆盖已有配置。同项目会话共享文件，不会自动创建 worktree。

## 2026-10-11：配置与文档交付

- `.env.example` 和 Linux 模板逐项说明用途、默认/示例值、取值范围和重启要求；安装器生成的配置保留注释。
- 文档按使用、部署、运维和开发重新组织，新增集中配置参考，补充 API、恢复与验收流程；中文和英文对应维护。
- 合并重复架构说明和独立需求验收页，移除历史修复流水记录。源码交付保留应用资源、测试代码和依赖锁文件，排除真实配置与运行产物。

已有实例不会因为更新模板而自动重写 `.env`。保留自己的值，按[配置参考](CONFIGURATION.md)核对；不要直接用模板覆盖线上配置。

## 2026-10-10：供应商模型目录与出站代理

供应商设置新增“获取模型”。成功后保存模型 ID 列表与获取时间，只有再次主动获取才更新；刷新页面和服务重启使用已保存的自定义目录。失败保留原列表，手工编辑仍可用。默认模型独立保留，获取不会切换供应商或重启执行器。

新增从 `.env` 读取出站 HTTP(S) 代理的支持，后端 fetch 在配置加载后启用代理，CLI 子进程继承环境。代理变量作用于实例，不需要逐个改供应商 URL。

升级时重新安装锁定依赖并构建、重启后端。旧 systemd 覆盖文件中的同名代理变量仍优先于 `.env`；按[运维指南](OPERATIONS.md)确认来源。未配置代理时沿用原网络行为。目录接口与格式限制见[供应商](PROVIDERS.md)。

## 2026-10-10：文件查看与本地入口

文件抽屉增加图片预览、放大、缩放与适应窗口；异常图片和超限文件提供错误反馈及下载路径。预览支持格式和限制见[使用指南](PRODUCT.md)。新增 Windows `.bat`、macOS `.command` 本地启动入口；首次依赖安装、密码设置和构建仍需完成。

## 2026-10-09 及此前：基础工作台能力

设置页调整为分区管理，覆盖供应商、扩展、执行环境、数据和账户；消息界面改进逐条记录与工具输出呈现。项目已包含会话操作、任务审批/排队、供应商切换、Skills/MCP、用量与迁移功能。当前支持边界见[执行器覆盖](CODEX-API-COVERAGE.md)，不以历史记录作为当前平台兼容承诺。
